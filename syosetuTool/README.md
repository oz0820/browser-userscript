# Syosetu Tool

小説家になろうを読みやすくするツール。PC・スマートフォン・タブレットで利用できます。  
ノベルピア・ノベルピンク・カクヨムにも一部対応（キーボードでのページ送り・スクロール）。

## 機能
**共通**

- 矢印（左右）キーで前・次の話に移動する
- Ctrlキーで次の話に移動する
- 矢印（上下）キーでページをスクロールする

**小説家になろう**

- 前書き・後書きを折りたたむ。1行の表示をタップ・クリックすると内容を開ける
- 「前・目次・次へ」を押しやすい大きさで表示し、ボタン全体をタップ・クリックできる
  - PCでは3つのボタンを本文と同じ幅に並べる
  - 第1話でも「目次」「次へ」の位置は変わらない
- 本文の前後やフッターの広告、画面下部に重なる広告を非表示にする

### インストール
- [tampermonkey](https://www.tampermonkey.net/)とかユーザースクリプトを実行できる拡張機能をインスコする。  
- [ここ](https://github.com/oz0820/browser-userscript/raw/main/syosetuTool/shosetu_tool.user.js)(このプロジェクトの最新コード)押す。  
- 指示に従ってインストール。  

### 使い方

|キー|動作|
|:---|:---|
|←|前のエピソードに移動|
|→|次のエピソードに移動|
|Ctrl（左右どちらも）|単独で押すと次のエピソードに移動|
|↑|上へ100pxスクロール|
|↓|下へ100pxスクロール|

キーボードショートカットは次のページで有効です。前・次の移動先がない場合、ページ送りは行いません。

- 小説家になろう（`ncode.syosetu.com`・`novel18.syosetu.com`）：連載の各話ページ
- ノベルピア・ノベルピンク：`/viewer/`以下のページ
- カクヨム：`/works/作品ID/episodes/`以下のエピソードページ

入力欄にフォーカスがある場合もショートカットが発動します。また、ブラウザー標準のキー動作は抑止していないため、上下キーでは100pxのスクロールに加えて通常のスクロールが起こる場合があります。
